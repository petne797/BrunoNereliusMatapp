# Agentinstruktioner

- Kontrollera att korrekt repo och arbetskatalog används innan ändringar.
- Läs relevant dokumentation och kontrollera Git-status före arbete.
- Håll taskens scope avgränsat och gör inga orelaterade refaktoreringar.
- Fatta inga implicita produkt- eller arkitekturbeslut; markera alternativ som Proposed eller öppna frågor.
- Ändra inte krav eller prioriteringar utan Product Owners uttryckliga beslut.
- Håll dokumentation, implementation och tester synkroniserade.
- Kör relevant testning och verifiera faktiskt repo-tillstånd före leverans.
- Använd branch, pull request och review för utvecklingsändringar.
- Förutsätt inte en kodstruktur eller teknisk stack som ännu inte har beslutats.
- Lägg inte till beroenden eller applikationskod utanför taskens uttryckliga scope.
