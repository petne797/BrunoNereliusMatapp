# Sprintar

## Nuläge: Sprint 0 – bootstrap

Projektet befinner sig i bootstrap/Sprint 0. Ingen tidigare sprinthistorik eller genomförd tasklista förs över.

Sprint 0 ska på hög nivå skapa beslutsunderlag för:

- produktdefinition,
- centrala användningsfall,
- senare MVP-avgränsning,
- domänmodell,
- arkitektur- och teknikval,
- infrastruktur och deployment,
- samarbetsmodell.

Först därefter är ett minimalt körbart applikationsskelett aktuellt. Ingen detaljerad Sprint 1-plan eller genomförd implementation dokumenteras innan den beslutats och faktiskt genomförts.

GitHub Projects diskuteras som möjlig framtida operativ backlog/sprinttavla men är inte etablerat ännu.
